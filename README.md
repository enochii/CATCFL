# Context-Aware Tabulation for CFL-Reachability

This repository contains the implementation of **CAT (Context-Aware Tabulation)**, a CFL-reachability solver.

If you use CAT in your research, please consider citing [our paper](https://dl.acm.org/doi/pdf/10.1145/3744916.3773222):

  author={Shi, Chenghang and Li, Lian},
